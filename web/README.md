# super-dictation-jp web(プロトタイプ)

音声を聞いてますに入る20秒ぶんの文章を聞き、下に出る2問に答える学習アプリの動くプロトタイプ。
仕様: `../概要.md`(一回5問制・スコア集計・各問題型)

## 起動

```bash
cd /Users/yuki/Downloads/super-dictation-jp/web
python3 -m http.server 8642
# → http://localhost:8642  (index.html がホーム)
```

ファイル直接ダブルクリック(file://)でも動きます(audio のみサーバー推奨)。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ホーム: きょうの採点(◎◯△✕)・レベル選択・7日ぶんの履歴 |
| `quiz.html?sid=…&i=…` | 1問=1ページ。音声再生(1回だけ)→問題→答え合わせ(採点印)→要約→次 |
| `data.js` | 問題データ(mdから自動生成、**編集しない**) |
| `assets/js/db.js` | IndexedDB(`super-dictation-jp` / stores: sessions, answers) |
| `assets/js/quiz.js` | 出題システム本体(ヘッダー進捗バー・再生速度も) |
| `audio/*.mp3` | 問題音声(Irodori-TTS v4.1-Small MLX版で生成。`tools/build_all.py` で全問ぶん作れる) |

## スコアの決まり

- **クイズ(Q1/Q2)1つ正解 = 1 点**。1問(ページ)に2つのクイズがあるので、1問 = 最大2点、1セット(5問)は **10点満点**
- 結果画面は「○ / 10 点」。ホームの「きょうの平均」「昨日までの平均」「7日履歴」は **セッションごとの正答率(%) の平均** と、その日の合計点を表示
- クイズページのヘッダーに常時 進捗バー(5問ぶんの採点セル ◎/△/✕/▢+「いま ○ 点」)。**◎=その問題のクイズ全正解(2点)、△=1つだけ正解(1点)、✕=全まちがい(0点)**。ページをまたいで復元される
- **5問を最後まで終えなかったセットは、なかったことになる**(ホームに戻った時点で、そのセッションの記録と回答を消す。出題回数にも数えない)
- ホームボタンを押すと「**ここでやめますか。**」の確認ポップが出る。「つづけて解く」で戻り、そのまま続けられる

## 音声つきデモ

- **標準レベルの5問**(2-01-1〜2-01-5)。あらかじめ音声を用意してある
- きょうの成績・履歴・出題回数(だし分け)**には数えない**(練習用)

## 音声のきき方

- **音声を最後まで聴いたら、初めて問題(クイズ)がひらく**。それまでは問題はぼかされて読めない(ことばが見えない)
- 音声のない問題は約1秒後に自動で出る
- プレイヤー右に **1倍 / 1.25倍 / 1.5倍** ボタン。選択は `localStorage(sdj-rate)` に保存され、次の問題ページにも引き継がれる
- **音声は各問題で1回だけ(答え合わせまでは)**: 最後まで聴き終わる途中なら一時停止→再開はできるが、答え合わせまでは再再生できない。**答え合わせをすると、上の「音声を聞こう」の再生ボタン(スペースキー)でもう一度聴けるようになる(何度でも可)**

## 数字の答えのかき方

- けたごとの空ます(十の位・一の位など)に 0〜9 を入れる(ポップは上から下へ 0→4、つぎの列に 5→9 の順)
- ますの下に **まとまり表示**(「こたえ 36個」など)があり、入れたけたが1つの数字として見える。入っていないけたは「▢」で示す
- 数え語(個/人/本/円…)は問題文の「何〇」から自動でとる。 取れない場合(「いくつ」など)は数字だけ表示

## ランダム選択(だし分け)

- レベル内で**出題回数の少ない問題から出る**: 0度の問題がなくなってから1度目、1度目がなくなってから2度目…(完了セットだけを回数に数える)
- 各回数帯の中ではランダムに選ぶ

## 問題型の実装

- `4択数字`(こたえが数) → **数字の空ます**: こたえのけた数ぶんのます(2けたなら「十の位・一の位」)。押すと **0〜9** をえらぶポップ
- `空白のます` → 「ます」を押すと選択肢ポップ(**画面の内側に収まるよう折り返し・位置調整をする**。狭い端末では2列になる)
- `回答文の穴埋め選択/虫食い選択` → 問題文 → **回答文プレビュー**([空欄1][空欄2]の位置に選んだことばが下線付きで入る)→ その下の 空欄1/空欄2 ますで入力
- `空白のます・桁ごと` → 百の位/十の位/一の位それぞれのます(押すと 0〜9 をえらぶ)
- `4択ことば・時こく` → 従来どおり選択肢ボタン
- `ダミーなし・記述` → テキスト入力

## 全量の自動生成(決定版)

問題データと全問題ぶんの音声をまとめて作る1本のツール:

```bash
cd /Users/yuki/Downloads/super-dictation-jp
/Users/yuki/Downloads/irodori-tts/.venv/bin/python tools/build_all.py
```

やること:
1. 問題md(簡単〜最難関.md)→ `web/data.js` 変換(400パターン/800問 の整合チェック付き)
2. 音声のない問題をすべて TTS 生成 → `web/audio/{問題id}.mp3`(1問 7〜10秒くらい。中断しても、もう一度実行すれば続きから)
- `--ids 1-02-1,2-03-1` / `--limit 20` / `--dry-run`(対象と所要だけ表示)/ `--force`(作り直し)/ `--skip-audio`(データだけ)
- web ページは index.html / quiz.html が data.js の全問題を扱うので、個別の問題ページ生成は不要

## データ更新

問題mdを直したら build_all.py を実行すれば全自動(データ変換+足りない音声を補充):

```bash
/Users/yuki/Downloads/irodori-tts/.venv/bin/python ../tools/build_all.py
```

md→data.js だけなら:

```bash
/Users/yuki/Downloads/irodori-tts/.venv/bin/python ../tools/build_all.py --skip-audio
```

## 音声を増やす

特定の問題だけ足す場合:

```bash
/Users/yuki/Downloads/irodori-tts/.venv/bin/python ../tools/build_all.py --limit 5
```

`web/audio/{問題id}.mp3` に置けばホーム→レベル選択でも鳴るようになる(ない問題は自動で「音声なし」扱い)。
